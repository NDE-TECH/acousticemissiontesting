# SEO + AI Search Launch Checklist

## Technical SEO
- [ ] GitHub Pages custom domain is `www.acousticemissiontesting.org`.
- [ ] HTTPS is enabled and forced after the certificate is available.
- [ ] The apex domain redirects to the `www` canonical host.
- [ ] `robots.txt` returns HTTP 200.
- [ ] `sitemap.xml` returns HTTP 200 and contains only canonical public URLs.
- [ ] `404.html` is served for missing URLs and remains `noindex,follow`.
- [ ] No page has accidental `noindex`.
- [ ] Canonical URLs exactly match the production URLs.
- [ ] No mixed-content HTTP assets are present.

## On-page SEO
- [ ] Every public page has one clear H1.
- [ ] Titles and meta descriptions are specific to each page.
- [ ] Important services and applications are linked from relevant pages.
- [ ] Image alt text describes the image rather than stuffing keywords.
- [ ] Technical claims and standards references are accurate and supportable.

## Structured data
- [ ] Validate JSON-LD after launch.
- [ ] Organization contact/address data matches the visible site and official company sites.
- [ ] Service structured data describes only services actually offered.
- [ ] Do not add fake ratings, reviews, awards, clients, accreditations or project claims.

## AI / answer-engine discoverability
- [ ] `llms.txt` is public and contains current canonical links.
- [ ] Pages answer specific inspection questions directly in visible HTML.
- [ ] Use precise headings, definitions, limitations and application conditions.
- [ ] Keep entity names consistent: IAIS India, IAIS UAE, and Acoustic Emission Testing.
- [ ] Update outdated pages instead of creating near-duplicate keyword pages.
- [ ] Do not hide content purely for crawlers or AI systems.

## Search engine launch
- [ ] Verify Google Search Console ownership.
- [ ] Submit `https://www.acousticemissiontesting.org/sitemap.xml`.
- [ ] Request indexing for the homepage and key service pages after launch.
- [ ] Set up Bing Webmaster Tools if required.
- [ ] Monitor indexing, crawl errors, Core Web Vitals and search queries.
